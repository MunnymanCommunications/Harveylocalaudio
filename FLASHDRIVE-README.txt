WHAT IS HARVEY?
===============

Harvey is a voice-powered AI assistant that runs completely on YOUR computer:

✓ 100% OFFLINE    - No internet needed after installation
✓ PRIVATE         - Your conversations never leave your computer
✓ FAST            - ~500ms response time (faster than cloud services!)
✓ SMART           - Uses Nemotron 3 Nano AI (30 billion parameters)
✓ YOUR VOICE      - Clone your own voice or use custom voices
✓ MULTILINGUAL    - Speaks 14+ languages fluently

TROUBLESHOOTING:
===============

Problem: "Python not found"
Solution: Install Python 3.10+ from python.org

Problem: "Ollama not found"
Solution: Install Ollama from ollama.com

Problem: "Model not loading"
Solution: Make sure this flash drive is still connected during install

Problem: "Permission denied" (Mac/Linux)
Solution: Right-click INSTALL-HARVEY.sh → Open With → Terminal

Problem: "Installation takes forever"
Solution: The AI model is 17GB! It takes time. Be patient ☕

ADVANCED OPTIONS:
================

Want to customize Harvey?

1. Change AI Model:
   - Edit: Harvey-AI/backend/config.yaml
   - Change: llm.model to different model
   - Run: ollama pull [model-name]

2. Change Voice:
   - Open desktop app → Voice Configuration
   - Select different voice or add custom voice sample

3. Change Language:
   - Desktop app → Voice Configuration → Language
   - Choose from 14+ languages

4. Performance Tuning:
   - Edit config.yaml
   - Reduce stt.model to "medium" for speed
   - Enable CUDA for GPU acceleration
